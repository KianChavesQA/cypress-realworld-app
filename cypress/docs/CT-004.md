# Caso de Teste: CT-004

## 1. Identificação do Caso de Teste

- **ID:** CT-004
- **Título:** Registro com informações incompletas
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [25/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Garantir que o sistema exiba mensagens de erro ao tentar registrar novo usuário sem preencher todos os campos obrigatórios.

## 3. Pré-condições

- O sistema deve estar disponível

## 4. Entradas de Teste

## 5. Procedimentos de Teste

1. Clicar no botão de cadastro.
2. Verificar se está na URL de cadastro.
3. Clicar no botão de registrar sem preencher os campos.
4. Verificar se aparece a mensagem de alerta de campo obrigatório.

## 6. Resultados Esperados

- Deve exibir mensagens de erro para campos obrigatórios não preenchidos
