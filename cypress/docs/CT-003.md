# Caso de Teste: CT-003

## 1. Identificação do Caso de Teste

- **ID:** CT-003
- **Título:** Registro de novo usuário
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [25/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Verificar se é possível registrar um novo usuário com informações válidas.

## 3. Pré-condições

- O sistema deve estar disponível

## 4. Entradas de Teste

1. Primeiro nome válido.
2. Segundo nome válido.
3. Username válido.
4. Password válida.

## 5. Procedimentos de Teste

1. Clicar no botão de cadastro.
2. Verificar se está na URL de cadastro.
3. Inserir primeiro nome válido.
4. Inserir segundo nome válido
5. Inserir userame válido.
6. Inserir password válida.
7. Inserir a mesma password válida.
8. Verificar se aparece a mensagem de sucesso.

## 6. Resultados Esperados

- Deve registrar um novo usuário com sucesso
