# Caso de Teste: CT-002

## 1. Identificação do Caso de Teste

- **ID:** CT-002
- **Título:** Login com usuário inválido
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [25/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Garantir que o sistema exiba a mensagem de erro ao tentar login com email ou senha incorretos

## 3. Pré-condições

- O sistema deve estar disponível

## 4. Entradas de Teste

- userData.userFail.username
  userData.userFail.password

## 5. Procedimentos de Teste

1. Verificar se esta na página de login.
2. Preencher o input de username com usuário inválido.
3. Preencher o input de password com password inválida.
4. Clicar no botão de login.
5. Verificar se aparece a mensagem de alerta de erro

## 6. Resultados Esperados

- Deve exibir uma mensagem de erro para credenciais inválidas

- **Requisito(s) relacionado(s):** RQ-002
