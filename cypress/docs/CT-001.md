# Caso de Teste: CT-001

## 1. Identificação do Caso de Teste

- **ID:** CT-001
- **Título:** Login com usuário válido
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [25/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Verificar se é possível efetuar login com creenciais válidas.

## 3. Pré-condições

- O usuário já deve estar cadastrado no sistema.

## 4. Entradas de Teste

- userData.userSucesss.username
  userData.userSucesss.password

## 5. Procedimentos de Teste

1. Verificar se esta na página de login.
2. Preencher o input de username com usuário válido.
3. Preencher o input de password com password válida.
4. Clicar no botão de login.
5. Verificar se o usuário está logado.

## 6. Resultados Esperados

- O sistema deve autenticar o usuário e redirecionar para a pagina inicial

- **Requisito(s) relacionado(s):** RQ-001
