# Caso de Teste: CT-005

## 1. Identificação do Caso de Teste

- **ID:** CT-005
- **Título:** Enviar dinheiro com saldo suficiente
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [26/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Garantir que é possível enviar dinheiro para um amigo quando o saldo da conta é suficiente.

## 3. Pré-condições

- O usuário deve possuir saldo

## 4. Entradas de Teste

1. userData.userSucess.username.
2. userData.userSucess.password.
3. Contato válido
4. Valor da transferência igual ou menor que o saldo
5. Nota aleatória

## 5. Procedimentos de Teste

1. Preencher o campo de nome de usuário com dados válidos.
2. Preencher o campo de senha com dados válidos.
3. Clicar no botão de login.
4. Verificar se o usuário está logado corretamente.
5. Iniciar uma nova transação.
6. Verificar se está na página de transações.
7. Selecionar o primeiro contato da lista para enviar dinheiro.
8. Preencher o valor da transferência menor ou igual ao saldo.
9. Preencher o campo de nota com uma frase aleatória.
10. Clicar no botão para realizar o pagamento.
11. Verificar se a mensagem de sucesso é exibida

## 6. Resultados Esperados

- Deve enviar o dinheiro para conta de um amigo quando o saldo for suficiente
