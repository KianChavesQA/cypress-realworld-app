# Caso de Teste: CT-007

## 1. Identificação do Caso de Teste

- **ID:** CT-007
- **Título:** Visualizar histórico de transações com sucesso.
- **Versão:** 1.0
- **Autor:** Kian Chaves
- **Data de Criação:** [26/08/25]
- **Revisão:** [26/08/25]

## 2. Objetivo

Verificar se é possível visualizar o histórico de transações de um usuário com suas transações anteriores exibidas corretamente.

## 3. Pré-condições

-Usuário autenticado.
-Usuário com histórico de transações valido.

## 4. Entradas de Teste

1. userData.userSucess.username
2. userData.userSucess.password

## 5. Procedimentos de Teste

1. Preencher o campo de nome de usuário com dados válidos.
2. Preencher o campo de senha com dados válidos.
3. Clicar no botão de login.
4. Verificar se o usuário está logado corretamente.
5. Clicar no botão de transações pessoais
6. Verificar se há transações pessoais.


## 6. Resultados Esperados

Visualizar histórico de transações do usuário
